Problem Definition & Governance Constraints

โจทย์ สิ่งที่ห้ามใช้ และข้อจำกัดถูกกำหนดก่อนเห็นผล

Objective

แบ่งกลุ่มผู้เรียน MOOC จากพฤติกรรมการเรียนจริง เพื่อสนับสนุนการวางแผนช่วยเหลือผู้เรียนอย่างรับผิดชอบ

Segment MOOC learners using observed learning behaviours to support responsible learner-support planning.

Governance

  • หนึ่งแถวต่อ userid_DI
  • Unsupervised behavioural segmentation
  • Outcome ถูก quarantine จน model lock
  • ใช้เพื่อวางแผนสนับสนุน ไม่ใช่ causal/high-stakes label

Model Strategy & Family Comparison

ทดลอง model × K/parameter ก่อนเลือก final: K-Means, HAC, GMM, DBSCAN, BIRCH และ MiniBatch

Family recommendation: K-Means · K เลือกภายหลังด้วย Gap one-SE. K-Means เหมาะกับข้อมูล percentile แบบ Euclidean, เสถียร, รองรับ cohort ใหญ่ และ assign ข้อมูลใหม่ได้. K-Medoids แสดง not_evaluated เพราะไม่มี implementation ที่ตรวจสอบได้ใน environment; ไม่ใช้ sampled approximation ปลอมเป็นโมเดลจริง.
